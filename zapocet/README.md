# Zápočet

Тест на оценку 3: найти второе максимальное число в массиве.
Rust-решение с комментариями находится в [`rust/src/bin/zapocet_E/main.rs`](../rust/src/bin/zapocet_E/main.rs).

Запуск из корня репозитория:

```sh
cd rust
cargo run --bin zapocet_E
```

Здесь остаются общие материалы тестов; реализации размещаются в каталогах соответствующих языков.

Переводы того же решения:

- [C#](../csharp/src/exercises/zapocet_E/Program.cs)
- [C++](../cpp/src/exercises/zapocet_E/main.cpp)
- [Java](../java/src/main/java/exercises/task_zapocet_E/Main.java)
